# ➕ Ajouter un transcript

1. Nouvelle note ici, nommée `Transcript - <Session courte> - <Speaker>` (ex : `Transcript - Plénière Talents - Chettaoui`).
2. Insère le template [[Template - Transcript]] (Ctrl/Cmd+P → « Insérer un modèle »).
3. Remplis `session:` et `speakers:` dans le frontmatter (wikilinks) + colle le transcript brut.
4. Ajoute dans la note de session une ligne : `**Transcript :** [[Transcript - ...]]`.
5. Analyse avec le [[Prompt d'analyse TGF AI Brain]] → crée les notions/citations → passe `statut: analysé`.

Voir le pipeline complet : [[TGF AI Brain]]. Exemple : [[Transcript - EXEMPLE - Plénière Stratégique]].
